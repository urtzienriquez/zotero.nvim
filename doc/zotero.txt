INTRODUCTION                                            *zotero-introduction*

zotero.nvim is a Neovim plugin that lets you browse your Zotero library
without leaving the editor. It provides a full-featured buffer-based UI
inspired by the Zotero desktop application, with:

  - A collections tree (left pane) with expand/collapse and item counts
  - An items list (right pane) with configurable columns and presets
  - A detail panel showing full metadata, abstract, tags, notes, and
    attachments
  - Search across your entire library
  - Sort by title, year, or date added
  - Item marking system: toggle marks, filter to show only marked items
  - Duplicate detection when importing PDFs
  - Create and trash collections
  - Open attached PDFs from within Neovim
  - Import PDFs directly into Zotero via the Connector API, with
    duplicate detection
  - Edit item metadata (requires companion Zotero plugin)

zotero.nvim reads your Zotero SQLite database directly — no Better BibTeX
export required.

==============================================================================
REQUIREMENTS                                            *zotero-requirements*

  - Neovim >= 0.10 (this is the `v0` branch; the `main` branch has the
    same features but needs Neovim nightly for the built-in vim.async)
  - sqlite3 CLI binary (install via your package manager, e.g.
    `sudo apt install sqlite3` or `brew install sqlite3`)
  - Zotero Connector enabled: Settings → Advanced →
    "Allow other applications on this computer to communicate with Zotero"
    (Required for PDF import, add-by-identifier, and metadata editing)
  - A local Zotero database at one of the standard locations:
    ~/Zotero/zotero.sqlite
    ~/.zotero/zotero.sqlite
    ~/.local/share/zotero/zotero.sqlite

INSTALLATION                                            *zotero-installation*

lazy.nvim~
>lua
    {
      "urtzienriquez/zotero.nvim",
      branch = "v0",
      config = function()
        require("zotero").setup({
          db_path = "~/Zotero/zotero.sqlite",  -- optional, auto-detected
        })
      end,
    }

>lua
    vim.pack.add({

After installing and restarting Zotero, the following features are available in
the edit buffer (opened with `ee` on an item):

  - :w or :ZoteroSave      Save changes to Zotero
  - <leader>zs             Save changes to Zotero (alternative)
  - g?                     List available field names for the item type
  - <leader>zk             Regenerate Better BibTeX citation key
  - q                      Close editor

USAGE                                                          *zotero-usage*

Open the Zotero library browser with:

  :Zotero

Or use the default keymap: |zotero-keymaps|

The browser opens in its own tab, with a split layout:

>ascii
  ┌──────────────┬──────────────────────────────────────┐
  │ My Library   │  #  Title          Author  Year Type │
  │ ├─ Biology   │  1  Paper A ...    Smith   2024 art  │
  │ ├─ Chemistry │  2  Paper B ...    Jones   2023 art  │
  │ └─ Physics   │                                      │
  ├──────────────┴──────────────────────────────────────┤
  │  Title: Paper A                                      │
  │  Authors: Smith, John                                │
  │  Abstract: ...                                       │
  └─────────────────────────────────────────────────────┘
<

Collections Pane~
  Navigate the tree with |j|/|k|. Press |<CR>| to select a
  collection (loads its items) or expand/collapse if it has children.
  Jump between sections (My Library, Feeds, Marked, Trash) with |]]|/|[[|.

Feeds~                                                        *zotero-feeds*
  Zotero stores each feed (and each group) as a separate library; only
  your personal library is shown under My Library. Subscribed feeds are
  listed in a Feeds section with unread counts (`Feeds (0)` when you have
  none yet).

  Managing feeds (companion plugin 1.2.1 or later):
  - aa on the Feeds header or a feed asks for a URL; Zotero
    checks it is an RSS/Atom feed, names it after the feed's title and
    fetches it (see |:ZoteroAddFeed|). |:ZoteroImportOPML| imports many.
  - dd on a feed unsubscribes from it.
  - R on a feed fetches new items; on the Feeds header it
    refreshes all feeds (also |:ZoteroRefreshFeeds|).

  Press |<CR>| on a feed to
  list its items. On a feed item, |<CR>| opens the preview and
  ob opens its link (URL, else DOI) in the browser; either
  marks the item read, as viewing it in Zotero does. rr toggles
  read/unread. Read state needs companion plugin 1.2.1 or later
  (|zotero-companion-plugin|).

  Feeds use the compact view by default (see `feed_view`), with unread
  items marked `●` (highlight group `ZoteroFeedUnread`); the marker goes
  away once an item is read. Otherwise feed items are
  read-only: editing, deleting, marking, attaching and moving them are
  refused.

Items Pane~
  Scroll items with |j|/|k|. Press |<CR>| to see the full item detail.
  Search with `ff` (see |zotero-search|), clear with `fc`. Sort with `st`
  (title), `sy` (year), `sd` (date added). Filter by item type with `ft`
  (or |:ZoteroFilterType|); the filter stays active when switching
  collections or feeds.

Search~                                                      *zotero-search*
  `ff` prompts for a query and lists the matching items in the current
  view: My Library, a collection or a feed. It combines with the item-type
  (`ft`) and tag (`fT`) filters. The query is shown in the winbar; `fc`
  clears it.

  Where a word is looked for~
  A plain word is matched against each item's
    - title, publication, abstract and date
    - creators (first and last names)
    - tags
    - DOI and citation key
  anywhere in the text (`clim` finds "Microclimate"), ignoring case and
  accents (`nunez` finds "Núñez"). A word of exactly 8 letters/digits also
  matches the item with that Zotero item key (`ABCD1234`).

  Field prefixes~
  A prefix limits a word (or phrase) to one field. Except for `ft:` and
  `year:`, it still matches anywhere in the field, ignoring case and
  accents.

  author:{word}   Creators: authors, editors… (first and last name, so
                  `author:"raymond huey"` works)
  title:{word}    Title
  pub:{word}      Publication (journal, book, …)
  abstract:{word} Abstract
  tag:{word}      Tags
  doi:{word}      DOI
  citekey:{word}  Citation key
  year:{year}     Year of the date: `year:2019`, or a range:
                  `year:2010-2020`, `year:2015-` (from 2015),
                  `year:-1990` (up to 1990)
  note:{word}     Child notes of the item and the annotations on its PDFs
                  (highlighted text and comments). A standalone note
                  matches itself.
  ft:{word}       The full text of the item's attachments, as indexed by
                  Zotero (Zotero Settings > Search) and stored in
                  `fulltext.sqlite` next to your `zotero.sqlite`. Matches
                  whole words, and a plain word also matches the start
                  of one: `ft:clim` finds "climate" but not
                  "microclimate". Only files Zotero has indexed can match.

  Operators~
  a b             Every word must match. `a AND b` and `a & b` say the
                  same (only the upper-case `AND` is an operator; `and`
                  is a word).
  "a b"           An exact phrase. Works after a prefix too:
                  `author:"raymond huey"`, `ft:"species distribution"`
                  (no prefix matching inside an `ft:` phrase).
  a OR b          Either one. `|` works the same: `a | b`. Only the
                  upper-case `OR` is an operator; `or` is a word.
  -a              Leave out items that match. Also `-"a b"`,
                  `-author:a`, `-ft:a`…

  OR binds tighter than AND (and the space): `x a OR b` and
  `a OR b AND x` both mean (a or b) and x. There are no parentheses.

  Operators inside a prefix~
  After a prefix, a quote may combine several words or phrases for that
  one field with `OR`/`|` and `AND`/`&`, with the same rule that OR binds
  tighter:

    author:"huey OR kearney"             Huey or Kearney
    author:"huey AND kearney"            both of them (the same as
                                         `author:huey author:kearney`)
    author:"raymond huey | kearney"      the phrase "raymond huey", or
                                         Kearney
    author:"huey OR kearney AND porter"  (Huey or Kearney) and Porter
    -author:"huey AND kearney"           not co-authored by both
    -author:"huey OR kearney"            by neither of them
    ft:"climate change OR global warming"
                                         either phrase in the full text

  A `-` in front leaves out what the whole quote matches. With no
  operator inside, the quote is a single phrase (`ft:"climate change"`).
  Without a prefix it is always a single phrase: `"huey OR kearney"`
  looks for that exact text.

  Anything that doesn't read as an operator is searched for as text:
  `OR`/`AND` at the start or end, a bare `-`, a quote with no closing quote, or
  a prefix with nothing after it (`author:`). Other `word:` forms are
  plain text, so a pasted URL or DOI just works.

  Examples~
    ft:"climate change" author:huey
                          Huey's papers whose PDF mentions climate change
    author:"huey OR kearney" year:2010-
                          by Huey or Kearney, from 2010 on
    author:"huey AND kearney" ft:thermal
                          co-authored by both, PDF mentions "thermal…"
    title:thermal -author:huey
                          "thermal" in the title, not by Huey
    niche OR "distribution model"
                          the word or the phrase, anywhere
    ft:"range shift" -ft:model
                          the PDF mentions range shifts and never
                          "model…"
    note:todo | note:check
                          items with a to-do in their notes
    10.1038/nature01286   the item with that DOI

  Notes~
  - `ft:` reads Zotero's full-text database while Zotero is running,
    without locking it. If that read fails (the file is missing, Zotero
    is writing to it, or your sqlite3 can't read it, see below), `ft:`
    terms match nothing and a warning is shown once.
  - `ft:` needs a sqlite3 built with FTS5, version 3.43 or newer. Linux
    distributions' sqlite3 has it; the one that comes with macOS does
    not. On a Mac, install Homebrew's (`brew install sqlite`) and put it
    first on your PATH, e.g. in your shell profile: >sh
      export PATH="$(brew --prefix sqlite)/bin:$PATH"
<   Neovim must be started from that shell (or have that PATH) to pick it
    up. The rest of the search works with either sqlite3; FTS5 only makes
    it faster.
  - Words shorter than 3 characters are matched more slowly, and without
    the accent folding for `note:` terms.
  - Zotero's own quick search has phrases and the notes/full-text modes,
    but no field prefixes, OR, NOT or AND operators: those only exist in
    its Advanced Search.

Item-type checklist~                                    *zotero-type-filter*
  `ft` opens a floating checklist of the item types in the current
  view (library, collection or feed), with item counts. Changes apply to
  the items list immediately:
    <CR> / <Space>  Show/hide the type under the cursor
    o               Show only the type under the cursor
    a               Show all types
    q / <Esc>       Close
    g?              Open this help

Tags~                                                          *zotero-tags*
  Tags work like in Zotero's own item list:
  - Colored tags: the tags you give a colour in Zotero (right-click a tag
    in Zotero's tag selector → Assign Colour…) get numbers 1-9 in that
    order. `t1`…`t9` toggle colored tag N on the item under the cursor or
    on a visual selection: if every selected item has it, it is removed
    from all of them, otherwise added to all. Items show a coloured ● per
    colored tag before their title.
  - `tt` opens a checklist of all tags showing which ones the item(s)
    have, to add or remove several at once (see |zotero-tag-assign|).
  - `fT` filters the items list by tag (see |zotero-tag-filter|); the
    collections pane has a Tags section (folded by default) where <CR> on
    a tag adds it to / removes it from that same filter.
  - `cc` on a tag (in the Tags section or the `tt` window) assigns or
    removes its colour and number key, like "Assign Colour…" in Zotero:
    pick one of Zotero's 9 colours, then its number (1-9). Zotero allows
    at most 9 colored tags.
  - `dd` on a tag deletes it from every item in your library, after
    asking, like "Delete Tag…" in Zotero. On a visual selection of tags
    (`V` + `j`/`k`, then `dd`) it deletes all of them after one question.
  Toggling tags needs companion plugin 1.3.0 or later, and `cc` / `dd`
  need 1.4.0 (|zotero-companion-plugin|); dots and filtering work without
  it. Feed items are read-only.

Item tags checklist~                                     *zotero-tag-assign*
  `tt` opens a floating checklist of all tags for the item under the
  cursor, or for every item in a visual selection: [x] the item(s) have
  the tag, [ ] they don't, [~] only some of the selected items do (Zotero's
  colored tags come first). Changes are applied in Zotero straight away,
  so you can add and remove several tags in one go:
    <CR> / <Space>  Add or remove the tag under the cursor ([~]: add it
                    to all selected items)
    n               Add a new tag
    cc              Assign/remove the colour of the tag under the cursor
    dd              Delete the tag under the cursor (or all tags in a
                    visual selection) from all items
    q / <Esc>       Close
    g?              Open this help

Tag checklist~                                           *zotero-tag-filter*
  `fT` opens a floating checklist of the tags in the current view, with
  item counts; Zotero's colored tags come first with their number. Checked
  tags are required: only items that have all of them are listed (like
  selecting several tags in Zotero's tag selector). The filter stays on
  when you switch collections or feeds and shows in the winbar:
    <CR> / <Space>  Require / stop requiring the tag under the cursor
    o               Require only the tag under the cursor
    a               Clear the tag filter
    q / <Esc>       Close
    g?              Open this help

Detail Panel~
  Shows full metadata for the selected item, including abstract,
  tags, notes, and attachments. Press |q| or |<Esc>| to close.

Edit Buffer~
  Opened with `ee` on an item. Edit the JSON representation,
  then type |:w| or |:ZoteroSave|, or press <leader>zs to save. Press K
  to see the valid field names for the item's type. Press <leader>zk to
  regenerate the Better BibTeX citation key.

KEYMAPS                                                    *zotero-keymaps*

Press g? in any zotero.nvim buffer to jump to its section below. These are
the defaults; every key can be changed or disabled via `keymaps` in
|zotero-setup()|.

Global~                                                 *zotero-global-maps*
  <leader>zz      Open/close Zotero browser
  <leader>zf      Fuzzy search all items

Keys come in two-key families named after what they do (o = open,
e = edit, a = add, y = yank, s = sort, f = filter, t = toggle view), and
`<family>?` opens help at that family. The g prefix is reserved for
navigation, never for actions.

Collections Pane~                                  *zotero-collections-maps*
  j / k           Navigate up/down (also <Down> / <Up>)
  ]] / [[         Next / previous section
  <CR>            Select collection, feed, Marked or Trash (loads items);
                  on a collection with children, also expand/collapse;
                  on the Feeds header, open/close Feeds
  zo zc za zR zM  Vim's own fold commands: My Library, Feeds, Tags and
                  collections with sub-collections are real folds (so zO,
                  zC, zA, zj/zk, [z/]z, zv... work too). My Library and
                  top-level collections start open, Feeds, Tags and deeper
                  collections start closed; the pane keeps your folds
                  when it refreshes.
  <CR> on a tag   Add it to / remove it from the tag filter (focus stays
                  here, so several tags can be combined; see |zotero-tags|)
  cc on a tag     Assign/remove its colour and number key (1-9)
  dd on a tag     Delete it from all items (asks first); on a visual
                  selection of tags, delete all of them
  <Tab> / <Esc>   Focus items pane
  aa              Add a collection (on Feeds or a feed: add a feed)
  dd              Trash the collection (on a feed: unsubscribe)
  R               Refresh (on a feed: fetch new items; on Feeds: all)
  tc              Toggle collections pane
  ts              Toggle statuscolumn (signs, line numbers)
  gl / gf / gm / gd   Go to My Library / Feeds / marked items / Trash
  g?              Open this help

Items Pane~                                              *zotero-items-maps*
  j / k           Navigate up/down (also <Down> / <Up>)
  gg / G          Go to first / last item
  <CR>            Show item detail
  R               Refresh (in a feed: fetch new items first)
  <Tab>           Focus collections pane
  dd              Trash item(s); permanent delete in Trash
  cm              Move item(s) to a collection
  cr              Remove item(s) from the collection you're viewing; they
                  stay in My Library (asks first; needs companion plugin
                  1.5.0 or later)
  mm              Toggle mark on item(s)
  rr              Toggle read/unread (feed items)
  g?              Open this help
  dd, cm, cr, mm and rr also work on a visual selection.

  Navigation~
  gl              Go to My Library
  gf              Go to the Feeds section (collections pane)
  gm              Show only marked items (again: back)
  gd              Go to Trash ("deleted")

Open~                                               *zotero-items-open-maps*
  oo              Open the attached file
  ob              Open the URL/DOI in the browser
  o?              Open this help

Edit~                                               *zotero-items-edit-maps*
  ee              Edit item metadata (see |zotero-edit-maps|)
  ef              Fix attachment / update item from a DOI or URL
  e?              Open this help

Add~                                                 *zotero-items-add-maps*
  aa              Attach a PDF to the item
  ai              Import a PDF as a new item
  an              Add an item by identifier (DOI/ISBN/PMID/arXiv)
  a?              Open this help

Sort~                                               *zotero-items-sort-maps*
  st              Sort by title
  sy              Sort by year
  sd              Sort by date added
  s?              Open this help

Filter~                                           *zotero-items-filter-maps*
  ff              Search (see |zotero-search|)
  fc              Clear search
  ft              Item-type checklist (see |zotero-type-filter|)
  fT              Tag checklist (see |zotero-tag-filter|)

Toggle view~                                      *zotero-items-toggle-maps*
  tv              Column view (configured/compact/normal/full)
  tc              Collections pane
  ts              Statuscolumn (signs, line numbers)
  t1 … t9         Toggle Zotero's colored tag 1-9 on the item(s); works on

Yank~                                               *zotero-items-yank-maps*
  yk              Yank the item's citation key

  y?              Open this help

  system clipboard) or the default register.

COMMANDS                                                  *zotero-commands*

:Zotero               Open the Zotero library browser
:ZoteroDebug          Print database connection info and statistics

                                                            *:ZoteroAddFeed*
:ZoteroAddFeed [{url} [{name}]]
                      Subscribe to an RSS/Atom feed. Prompts for the URL
                      when omitted; the name defaults to the feed's title.

                                                         *:ZoteroImportOPML*
:ZoteroImportOPML {file}
                      Subscribe to the feeds in an OPML file. Feeds you
                      already follow are skipped.

                                                       *:ZoteroRefreshFeeds*
:ZoteroRefreshFeeds   Fetch new items for all feeds.

                                                          *:ZoteroFilterType*
:ZoteroFilterType [all | {type}... | -{type}...]
                      Filter the items list by item type. Without
                      arguments opens the checklist. `all` clears the filter,
                      `book thesis` shows only those types, `-webpage -note`
                      hides those types.
